# 私人銀行貸款及資金分配追蹤系統

一個單一檔案的網頁 App（只有 `index.html`），用瀏覽器就能打開，用來追蹤銀行貸款、資金分配到哪裏、以及還款進度。

## 這個 App 有什麼功能

| 區塊 | 用途 |
|---|---|
| 頂部 KPI 卡 | 總貸款額、借多了多少、尚欠本金、已還款金額一眼看清 |
| 資金分配明細 | 每一筆資金用到哪裏（買股票、還銀行借款、入貨…），並實時顯示剩餘可用 |
| 各銀行借款分佈 | 每間銀行的「原有貸款 vs 額外加借 vs 已還款」 |
| 還款紀錄 | 逐筆記錄還本、利息、日期 |
| 圖表 | 用 Chart.js 畫出分配比例與各銀行佔比 |
| 個人密碼鎖 | 開網站要先輸入自己設定的 PIN |
| 隱私模糊 | 一鍵把畫面金額打模糊，方便在別人旁邊看 |
| 備份 / 還原 | 匯出 JSON 備份檔、或貼上備份代碼還原 |

## 資料存在哪裏？兩種模式

**模式 A：只存這台電腦（預設）**
所有財務資料和 PIN 密碼都只存在**你自己電腦的瀏覽器**裏（瀏覽器內建的 LocalStorage）。這個網站沒有任何後端伺服器，所以別人打開網址只會看到內建的**範例資料**。
- 換電腦、換瀏覽器、或清除瀏覽器資料，數字就會消失 → 請定期用「下載完整備份檔 (.json)」備份。
- **千萬不要把備份的 .json 檔上傳到公開地方**，那個檔案裏面才是你的真實數字。

**模式 B：雲端同步（讓不同電腦共用同一份）**
點畫面左下角的 **☁️ 雲端同步**，貼上你自己的 GitHub 授權碼（token），資料就會存到你的 GitHub **私人**資料庫 `kwanabc/finance-vault`。之後在任何電腦打開這個網址、貼上同一組授權碼，就會看到同一份資料。
- 資料會離開這台電腦、經加密連線（HTTPS）送到 GitHub。若你要求「任何資料都不上傳」，就不要開這個功能。
- 授權碼要自己保管好，它等於這本資料庫的鑰匙。
- 每次修改後會**自動上傳**；打開網站時若雲端版本較新，會自動載入雲端版本（同步前的本機版本會自動備份，可用「還原同步前的本機版本」救回）。

## 怎麼使用

1. 直接開網址（GitHub Pages），或在電腦上雙擊 `index.html`。
2. 第一次進入時設定自己的 PIN 密碼（只存在你的瀏覽器）。
3. 用「+ 新增」按鈕輸入貸款、資金分配、還款紀錄，所有紀錄都可以隨時修改或刪除。
4. 想從零開始：用「清空所有紀錄」；想回到示範畫面：用「重設為預設範例數據」。

## 技術說明

- 純前端單檔：HTML + Tailwind CSS（CDN）+ Chart.js（CDN），沒有建置步驟、沒有套件要安裝。
- 資料存放：`localStorage`（key: `hk_private_loan_tracker_v1`，PIN: `hk_private_loan_tracker_pin_v1`）。
- 雲端同步設定：`hermes_sync_cfg_v1_loan-tracker`（授權碼另存於 `hermes_sync_token_v1`，兩個 App 共用）。
- 同步用 GitHub Contents API（`api.github.com`），檔案路徑 `loan-tracker.json`。
- 修改網站：直接用文字編輯器改 `index.html` 再上傳即可。

> PIN 鎖只是防止別人隨手看到畫面，不是加密。若同時開了雲端同步，敏感數字也會存在你的 GitHub 私人資料庫裏。
